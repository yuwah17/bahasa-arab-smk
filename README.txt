WEBSITE PEMBELAJARAN BAHASA ARAB SMK
====================================

Isi:
- index.html : halaman website
- style.css  : tampilan responsif
- app.js     : materi 12 bab, kamus, kuis, dan progres belajar
- assets/    : ilustrasi header

CARA MENJALANKAN OFFLINE:
1. Ekstrak ZIP.
2. Buka folder website_bahasa_arab_smk.
3. Klik dua kali index.html.
4. Website dapat berjalan di browser modern. Font Google akan memakai font cadangan jika internet tidak tersedia.

CARA PUBLIKASI GRATIS:
1. Buat akun GitHub.
2. Buat repository baru (misalnya bahasa-arab-smk).
3. Unggah semua isi folder ini ke repository.
4. Buka Settings > Pages.
5. Pada Build and deployment pilih Deploy from a branch.
6. Pilih branch main dan folder /(root), lalu Save.
7. Tunggu proses publikasi. GitHub akan memberikan alamat website publik.

CATATAN:
- Website ini merupakan versi statis (HTML, CSS, JavaScript), tanpa login dan tanpa server.
- Progres bab disimpan di perangkat/browser masing-masing murid (localStorage), bukan tersinkron antarperangkat.
- Untuk publikasi, unggah semua file dan folder, jangan hanya index.html.
- Guru dapat mengubah materi di app.js.
